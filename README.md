# 📚 Лабораторная работа №1: Каркас приложения и базовый REST API

## Цель работы
Получение практических навыков создания веб-приложения на FastAPI, настройки маршрутизации, использования Pydantic-моделей и реализации базового CRUD-интерфейса без использования базы данных (хранение в оперативной памяти) для предметной области «Интернет-магазин».

## Выполненные задачи
- [x] Инициализирован проект со структурой, рекомендованной методическими указаниями (`app/api/v1`, `app/schemas`, `app/services`).
- [x] Реализована схема данных **Product** (Товар) с использованием Pydantic v2 (`ProductCreate`, `ProductRead`, `ProductUpdate`) для валидации входных и выходных данных.
- [x] Настроены обязательные эндпоинты версии `v1`:
  - `GET /api/v1/products` — получение списка всех товаров.
  - `GET /api/v1/products/{product_id}` — получение товара по ID.
  - `POST /api/v1/products` — создание нового товара (статус `201 Created`).
  - `PUT /api/v1/products/{product_id}` — обновление данных товара.
  - `DELETE /api/v1/products/{product_id}` — удаление товара (статус `204 No Content`).
- [x] Реализовано временное хранилище данных в оперативной памяти (словарь `_items` внутри класса `InMemoryProductService`) согласно заданию первой лабы.
- [x] Обеспечена корректная обработка ошибок: `404 Not Found` при отсутствии объекта, `422 Validation Error` при невалидных данных.
- [x] Настроена автоматическая интерактивная документация OpenAPI (Swagger UI).
- [x] Протестированы все CRUD-операции через Swagger UI.

## Ход выполнения работы

### 1. Создание схем данных (Pydantic)
В файле `app/schemas/product.py` были описаны схемы для валидации. Входные данные проверяются на минимальную длину строки и положительное значение цены (`price > 0`). 
Схема `ProductRead` включает в себя `id` и `created_at`, а также имеет настройку `from_attributes = True` для корректной сериализации.

### 2. Создание сервиса (временное хранилище)
В файле `app/services/product.py` был создан класс `InMemoryProductService`. Вместо базы данных он использует обычный словарь Python (`dict`). 
Класс содержит методы:
- `list()` — возвращает список всех словарей.
- `get()` — ищет товар по ID.
- `create()` — генерирует новый ID, добавляет текущее время (`datetime.utcnow()`) и сохраняет товар в словарь.
- `update()` — обновляет только те поля, которые были переданы.
- `delete()` — удаляет товар из словаря по ID.

### 3. Настройка маршрутов (API)
В файле `app/api/v1/products.py` был создан `APIRouter` с префиксом `/products`. 
Маршруты обращаются к методам сервиса. Если объект не найден, выбрасывается исключение `HTTPException` со статусом `404`. При успешном создании возвращается `201`, при удалении — `204`.

### 4. Точка входа
В файле `app/main.py` было инициализировано приложение `FastAPI`, и к нему подключен роутер с префиксом `/api/v1`.
